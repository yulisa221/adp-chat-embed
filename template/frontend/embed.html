嵌入到你的网站

把下面两行代码放进任意网页即可使用，不需要 iframe，也不用改后端。右侧就是内嵌效果，右下角是悬浮气泡效果。

① 悬浮气泡（右下角）

② 嵌入到页面中的某个区域

容器需要有高度，例如 <div id="chat" style="height:600px"></div>。

常用配置

配置说明
title / avatar / greeting / questions名称、头像、欢迎语、示例问题；不填则用站点默认值
theme: { primaryColor, mode, radius, fontFamily }主色、亮 / 暗色、圆角、字体
position / width / height / bubbleIcon / open气泡位置（right / left）、面板尺寸、按钮图标、是否默认展开
history是否显示历史会话，默认显示
userToken实名用户：传入你后端签发的用户凭证（字符串或返回凭证的函数），历史按用户隔离；不传则按浏览器匿名隔离
customCss注入到对话框内部的额外 CSS，用于深度定制

返回值

const chat = ADPChat.mount(...)，可调用 chat.open()、chat.close()、chat.newChat()、chat.send('你好')、chat.destroy()。
